# الذهب الأسود — V4 Store Release

This build consolidates the store direction reached in the conversation and applies the supplied UI reference as the visual target.

### Visual
- Black / gold / warm cream identity.
- Wide editorial hero with spice imagery.
- Compact category rail and six-column desktop product presentation.
- Two-column mobile catalog cards.
- App-like bottom navigation and safe-area spacing.
- New spice category artwork and brand mark.
- Readable light/dark themes.

### Commerce
- Persistent cart.
- Favorites for guests and authenticated customers.
- Product detail flow with weights, gallery, share, favorite, cart and WhatsApp.
- Checkout and order creation remain connected to the existing backend.

### Account
- Orders, expandable details, status timeline, favorites and profile views.
- Mobile account navigation.

### Admin
- Existing product editing, pricing by kilo, stock, categories, images, SEO and preview controls are retained.

### PWA
- Existing manifest, service worker, install prompt and app shortcuts are retained.

### Android next
Use this V4 as the web/PWA source before packaging with Capacitor. For Google Play, use target SDK/API 36 in the Android wrapper and keep server secrets out of the APK.
